# UI/UX Design System

A professional skill for designing modern user interfaces, visual hierarchies, and component layouts for rider and admin platforms.

## When to Use
- Designing mobile app screens, dark-mode themes, and high-contrast dashboards.
- Establishing UI component structures (cards, navigation bars, badges, interactive toggles).
- Planning layout grids for responsive web and mobile viewports.

## Core Guidelines
1. **Visual Hierarchy**: Prioritize critical user actions (like live map radar, status toggles, and emergency buttons) using high-contrast surface colors and clear typography scales.
2. **Color Psychology**: Utilize sleek, modern dark modes paired with neon or vibrant accent highlights (ideal for automotive, tech, and community apps).
3. **Consistency**: Maintain uniform spacing, border radiuses, and padding tokens across both mobile apps and web administrative dashboards.
