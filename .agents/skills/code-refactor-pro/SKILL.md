# Code Refactor Pro

A professional skill for refactoring and architectural restructuring of full-stack applications.

## When to Use
- Splitting monolithic projects into clean multi-repository architectures (e.g., backend, mobile app, and admin ERP dashboards).
- Eliminating configuration bloat and circular dependencies.
- Optimizing database queries, API response times, and state management.

## Core Guidelines
1. **Separation of Concerns**: Ensure strict boundaries between business logic, data persistence, and UI presentation layers.
2. **Environment Isolation**: Keep sensitive API keys, secrets, and database credentials isolated inside `.env` configurations.
3. **Clean Module Boundaries**: Use clear export/import contracts between shared utility modules and feature components.
