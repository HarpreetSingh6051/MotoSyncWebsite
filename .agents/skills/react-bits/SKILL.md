---
name: react-bits
description: Integrate selected React Bits components into React websites with verified dependencies, licensing, and accessible motion.
---

Use https://reactbits.dev/ and https://reactbits.dev/get-started/installation as current references. React Bits supplies component source, not a universal runtime package. Choose the TypeScript CSS or Tailwind variant matching the repository. Inspect the actual source and required dependencies before adding it. Pin upstream source to a commit and retain its license; the upstream license includes Commons Clause, so do not describe it as plain MIT.

Match the existing design tokens. Use a small number of purposeful effects. Check keyboard and touch access, reduced motion, offscreen animation, cleanup, SSR, and fallback content. Do not attribute hand-written effects to the library. Run repository checks and preview narrow and wide layouts when available.
