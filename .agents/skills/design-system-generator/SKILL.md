# Design System Generator

A professional skill for building cohesive, scalable design systems for modern web and mobile applications (such as React, Tailwind CSS, and mobile UI frameworks).

## When to Use
- Designing color tokens, spacing scales, and typography hierarchies.
- Creating reusable UI component guidelines (buttons, cards, modals, navigation bars).
- Ensuring dark mode accessibility and WCAG contrast compliance.

## Core Guidelines
1. **Color Tokens**: Define a semantic palette (primary, neutral, surface, accent, destructive) with clear contrast ratios.
2. **Typography**: Establish a consistent font scale with fluid or responsive scaling rules.
3. **Component Architecture**: Build modular, headless or styled components with explicit props and state variants.
